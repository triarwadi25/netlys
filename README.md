# NETLYS (QGIS)
Road network analysis tools for the QGIS Processing Toolbox.

Install: Plugins > Manage and Install Plugins > Install from ZIP.
Use: Processing Toolbox > NETLYS.

- Service Area > Network Area (Distance/Time, Multi-Class) - Overlap / Dissolve / Split
- Routing and Accessibility > Shortest & Longest Path
- Routing and Accessibility > Distance/Time to Nearest Facilities (OD Matrix)
- Network Metrics > Network Connectivity (Beta & Gamma)

Requirement: road network line layer in a projected CRS with meter units.
